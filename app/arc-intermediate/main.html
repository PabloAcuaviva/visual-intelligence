⌨️ Keyboard Shortcuts

  • ← / → - Navigate steps (or pairs/steps in preview)
  • Ctrl+Z / Cmd+Z - Undo
  • Ctrl+Y / Cmd+Shift+Z - Redo
  • Ctrl+S / Cmd+S - Save task
  • C or Ctrl+C - Copy selected cells
  • V or Ctrl+V - Paste to selected cell
  • D - Copy current step forward
  • 0-9 - Quick color select
  • Esc - Close modals / Cancel line
  • ? - Toggle this help

Tip: Click 🔍 on pairs or timeline steps to view them larger. Use ← → to navigate in preview mode.
